# Kanji Cards / Kanji Kartları

A free flashcard app for studying the 2,212 JLPT N5–N1 kanji.
JLPT N5–N1 seviyelerindeki 2.212 kanjiyi çalışmak için ücretsiz bir kart uygulaması.

🌐 **Web version / Web sürümü:** https://bollattime.github.io/kanjicardapp/

## Features
- 2,212 kanji from JLPT N5 to N1
- On'yomi and kun'yomi readings
- English and Turkish meanings
- Example words with readings for every kanji
- Text-to-speech using the device's Japanese voice
- Favorites and search
- Kanji grouped by radical
- Filter by level
- Light and dark theme
- Works offline, data updates automatically
- No ads, no account needed

## How to use
| Screen | What it does |
|---|---|
| **Cards** | Shows the kanji, its readings, meaning and example words. Swipe left/right or use the arrows to move; tap 🔀 to shuffle. |
| 🔊 | Reads the kanji or word aloud in Japanese. |
| ♡ | Adds the kanji to your favorites. |
| **Radical tag** | Tap the radical on a card to see all kanji that share it. |
| **Menu → All kanji** | All kanji in a grid, with search (by kanji, reading or meaning) and a level filter. |
| **Menu → Radicals** | 194 radicals, grouped by stroke count. |
| **Menu → Favorites** | Your favorite kanji, with search. |
| **Menu → Card level** | Chooses the level (N5–N1) to study. |
| **Settings** | Language (Türkçe / English), data version and sources. |
